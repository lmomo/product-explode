# 六轴工业机械臂 · 3D 分阶段拆解展示站

基于 Vite + Three.js 的纯前端产品拆解演示站，全部几何体由代码程序化生成，
无任何外部模型 / 贴图 / CDN 资源，构建产物使用相对路径（`--base ./`）。

## 开发 / 预览

```bash
npm install
npm run dev            # 开发服务器 http://localhost:5173
npx vite build --base ./   # 生产构建，输出到 dist/
npx vite preview --port 5180   # 预览构建产物
```

## 功能

- **六大部件代码建模**：底座 / 腰部转台 / 大臂 / 小臂 / 手腕 / 末端夹爪，
  按真实关节层级（J1~J6）组织，各部件独立材质实例。
- **分阶段拆解 / 复原**：底部进度条（0~100%）可任意拖动；
  `单步拆解` / `单步复原` 按 6 个阶段推进；`一键拆解` / `一键复原` 连续播放；
  所有过渡使用 easeInOutCubic 缓动。
- **标签**：3D 场景中每个部件带 HTML 标签 + SVG 引线，显示名称与用途；
  标签停靠视口两侧并自动避让。
- **拾取与详情**：点击 3D 部件或左侧清单即可高亮（emissive 高亮）并在右侧面板
  展示用途、结构说明、关节与关键规格。
- **深色科技风**：深色背景 + 网格地面 + 发光环 + 环境光照（本地 RoomEnvironment）。

## 目录

```
index.html          页面结构
src/main.js         交互逻辑（进度 / 单步 / 拾取 / 高亮 / 动画循环）
src/model.js        机械臂程序化建模
src/parts.js        部件名称 / 用途 / 规格数据
src/scene.js        渲染器 / 相机 / 光照 / 场景
src/labels.js       3D 标签与引线
src/ui.js           左侧清单 + 右侧详情面板
src/styles.css      深色科技风样式
```
